## Before Publishing Checklist

### Code Changes Needed:
- [ ] Change `useTestAds = false` in `ad_config.dart`
- [ ] Verify all Ad Unit IDs are production IDs
- [ ] Remove any debug logs if needed
- [ ] Build release APK: `flutter build appbundle --release`

### Play Console Setup:
- [ ] Create Google Play Developer account ($25 one-time fee)
- [ ] Create Privacy Policy page (host on Google Sites, GitHub Pages, etc.)
- [ ] Prepare all screenshots (take on real device for best quality)
- [ ] Create Feature Graphic (1024 x 500)
- [ ] High-res icon (512 x 512)
- [ ] Fill in Data Safety form (no data collected)
- [ ] Set up Content Rating questionnaire
- [ ] Choose Countries for distribution

### After Publishing:
- [ ] Wait 24-48 hours for ads to start filling
- [ ] Monitor crash reports in Play Console
- [ ] Respond to user reviews
